# NVD 自生活，實用工具箱 - 專案開發與架構說明文件

本專案是一個專為高效率工作設計的實用工具推薦與導航網站。透過直覺的分類篩選、即時關鍵字搜尋與個人收藏功能，協助使用者快速找到適合的 AI、生產力、設計、文件處理與工程開發工具。

---

## 📂 專案目錄結構

專案採用輕量且高效的前端架構，完全使用原生技術（Vanilla HTML/CSS/JS）進行開發：

```text
NVD 自生活/
├── index.html              # 網站主網頁（HTML5 結構、i18n 標記與無障礙優化）
├── styles.css              # 視覺設計與響應式樣式表（含雙色主題、Modal 與 RWD 斷點）
├── script.js               # 核心邏輯腳本（i18n 翻譯庫、主題切換、搜尋與渲染）
├── backup.ps1              # 自動備份腳本（一鍵打包網頁原始碼為 ZIP）
├── README.md               # 專案開發與架構說明文件（本檔案）
└── NVD 自生活(工具)/        # 實用工具安裝包存放目錄
    ├── NoteLM_輕鬆上架包.rar  # NoteLM 智慧簡報還原助理安裝壓縮檔
    └── 萬物歸一_長輩專用版.rar # 萬物歸一轉檔助理安裝壓縮檔
```

## 🎨 核心設計系統與視覺美學

網站視覺設計注重現代感與直覺互動，樣式定義於 `styles.css` 中，採用以下設計規範：

1. **色彩系統 (全雙色模式變數)**:
   - 採用基於 CSS 變數的動態主題設計，支援**淺色模式**與**深色模式**（藉由 `body[data-theme="dark"]` 切換）。
   - **主色調**: `#ff6842` (溫和暖橘)，象徵高效與能量。
   - **輔助色**: `#18a999` (青碧綠)，用於圖示主題與狀態。
   - **背景與表面**:
     - 淺色模式下為極簡灰藍底面（`#f7f8fb` 與 `#ffffff`），頁尾特化為全白清新風格（`--footer-bg: #ffffff`）。
     - 深色模式下為高對比深邃藍灰底面（`#101214`、`#1b1d21` 與 `#272a30`）。
   - 全域設定了平滑的主題轉換過渡動畫（`transition: background-color 0.3s, color 0.3s`）。

2. **微互動與動畫**:
   - **卡片懸停效果 (Card Hover)**: 當滑鼠游標懸停在工具卡片上時，卡片會向上平移 `6px`，並觸發內部投影與陰影加深效果。
   - **收藏按鈕 (Favorite Toggle)**: 愛心按鈕在點擊時會有微幅縮放動畫，激活狀態下會轉換為滿心橘紅色。
   - **流暢導覽 (Scroll Behavior)**: 啟用全域平滑滾動（Smooth Scrolling）。

3. **響應式布局 (Responsive Design)**:
   - 使用 CSS Grid 與 Flexbox 實現彈性布局。
   - 支援三階段斷點：
     - 寬螢幕：3 欄工具卡片排列。
     - 平板（< 980px）：導覽列支援 Flex 換行，網格自動切換為 2 欄。
     - 手機（< 640px）：網格自動切換為單欄，並自適應按鈕寬度。

## 🛠️ 技術實作與功能特點

### 1. 語意化 HTML 與無障礙優化
* 遵循現代網頁無障礙標準（WAI-ARIA），使用 `<header>`, `<main>`, `<section>`, `<article>`, `<footer>` 等語意標籤。
* **搜尋優化**：移除了不正確的 `role="tablist"`。搜尋框改為 `div.search-box` 包裹，並利用 `.visually-hidden` 類別為螢幕閱讀器預留專屬的 `<label>` 元素。

### 2. 多語言國際化系統 (i18n)
* **雙語對照**：提供繁體中文（`zh`）與英文（`en`）雙語切換。
* **自適應標籤**：使用 `data-i18n` 與 `data-i18n-placeholder` 屬性標記靜態網頁元素。當語言切換時，JS 會動態解析 `translations` 對照表並即時替換文字內容與 placeholder，同時更新網頁宣告 `<html lang="...">` 的無障礙語系。
* **客製化下拉選單**：重構原生 select 為自訂選單（`.language-menu`），導入 `role="listbox"`, `role="option"`, `aria-haspopup="listbox"`, `aria-expanded` 與 `aria-selected` 等無障礙標籤。
  * **滑鼠互動**：展開選單時伴隨 `.language-options` 的淡入滑出動畫與 Chevron 圖示旋轉效果，支援點擊選單外部任意處自動關閉。
  * **鍵盤無障礙**：選單展開時若按下 `Esc` 鍵，將自動關閉選單並將焦點退回主按鈕（`languageToggle.focus()`），以提供友善的鍵盤操作體驗。
* **記憶體快取**：使用者選取的語言狀態會自動快取至瀏覽器的 `localStorage`（鍵名為 `nvd-language`），確保下次造訪時自動載入相同語言。

### 3. 深淺色主題切換 (Theme Toggle)
* **動態變數切換**：透過修改 `document.body.dataset.theme` 以切換 CSS 變數值，配合 FontAwesome 圖示（太陽與月亮）即時更新開關視覺。
* **記憶體快取**：主題狀態會自動快取至瀏覽器的 `localStorage`（鍵名為 `nvd-theme`），實現無縫的跨工作階段體驗。

### 4. Wabay 風格卡片視覺設計
* 工具網格（Tool Grid）中的卡片均採用 Wabay 設計規範：
  * **視覺區塊**：頂部設置獨立的漸層背景（`card-header-visual`）與圓角圖示徽章（`tool-icon-badge`）。
  * **內容主體**：包含精緻的標籤群組（`tag-list`）、雙語對應的工具標題與三行高度限制的短評描述。
  * **底部工具列**：左側為「愛心收藏按鈕」，右側配置顯眼的行動按鈕。

### 5. 使用說明 Modal 彈出視窗
* **互動模式**：點擊導覽列「使用說明」時觸發淡入滑出動畫，開啟半透明磨砂背景遮罩與 Modal 主視窗，內含雙語轉換之極簡步驟與常見問題。
* **多元關閉**：支援關閉按鈕、遮罩點擊、或鍵盤 `Esc` 鍵關閉彈窗，並在開啟時自動鎖定背景滾動。

### 6. 運作時狀態管理 (State Management)
藉由 JavaScript 的單一 `state` 物件統籌管理搜尋關鍵字、當前分類 Key、語系、主題與收藏清單（`state.favorites` 採用 `Set` 結構以求高效搜尋與去重）。

## 📝 專案維護與擴充指南

### 如何新增推薦工具（i18n 結構）
若要向網站中新增工具，請開啟 `script.js` 並於 `tools` 陣列中新增一個包含雙語欄位的物件：

```javascript
{
  id: 11, // 請確保 id 唯一不重複
  categoryKey: "document", // 必須對應已有的分類 Key (ai, office, document, design, dev)
  url: "https://example.com", // 官方連結或雲端下載路徑
  imageIcon: "fa-solid fa-star", // 參考 FontAwesome 6 圖示庫
  i18n: {
    zh: {
      name: "新工具名稱",
      description: "簡短描述該工具的核心優勢與解決的痛點。",
      tags: ["標籤一", "標籤二"]
    },
    en: {
      name: "New Tool Name",
      description: "Briefly describe the key benefits and solved pain points of the tool.",
      tags: ["Tag 1", "Tag 2"]
    }
  }
}
```
